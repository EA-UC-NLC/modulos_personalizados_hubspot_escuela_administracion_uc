# 🔘 Botones CTA

Colección de variantes de botones y llamadas a acción. Múltiples estilos para diferentes propósitos y jerarquías.

## 📋 Descripción

4 variantes de botones CTA incluidas en un módulo:
1. Azul primario
2. Dorado/Amarillo
3. Blanco con borde azul
4. Azul oscuro con icono

## 📐 Especificaciones

- **Ancho**: 600px (contenedor)
- **Padding botón**: 14-16px vertical, 40-50px horizontal
- **Border radius**: 4-6px
- **Sombra**: Según color
- **Font**: Bold, 13-15px

## 🎨 Variantes de Botones

### Botón Primario (Azul)
```
Fondo: #00b0db
Texto: Blanco
Sombra: 0 4px 12px rgba(0,176,219,0.3)
```
**Uso**: Registros, inscripciones, acciones principales

### Botón Secundario (Dorado)
```
Fondo: #ffd700
Texto: #03122E (oscuro)
Sombra: 0 4px 12px rgba(255,215,0,0.2)
```
**Uso**: "Ver más", información, detalles

### Botón Terciario (Blanco + Borde)
```
Fondo: #ffffff
Texto: #00b0db
Borde: 2px solid #00b0db
```
**Uso**: Descargas, recursos, acciones secundarias

### Botón con Icono
```
Fondo: #4a5f9d
Texto: Blanco + Emoji/Icono
```
**Uso**: Contacto, información, envío
