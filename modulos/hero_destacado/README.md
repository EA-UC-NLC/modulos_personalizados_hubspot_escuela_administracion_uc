# ⏰ Hero Destacado

Banner urgente para promociones limitadas, descuentos, ofertas especiales y anuncios prioritarios.

## 📋 Descripción

Diseño con sentido de urgencia. Incluye indicadores visuales (contador de cupos y días disponibles) con gradiente azul destacado.

## 📐 Especificaciones

- **Ancho**: 600px
- **Altura**: ~350px
- **Colores**: Gradiente azul con acento dorado
- **Compatibilidad**: Email clients

## 🎨 Elementos

- Badge "⏰ OFERTA LIMITADA"
- Título principal (40px, bold)
- Descripción con beneficio
- 2 contadores visuales (Cupos, Días)
- Botón CTA dorado prominente
- Disclaimer pequeño (legal)

## 🔧 Variables Personalizables

```
- Tipo descuento (porcentaje, beneficio)
- Descripción oferta
- Cupos disponibles
- Días restantes
- Texto botón CTA
- URL destino
- Texto disclaimer
```

## 📋 Checklist

- [x] Urgencia visual
- [x] Contadores dinámicos
- [x] CTA destacado
- [x] Email-safe

## 💡 Casos de Uso

- Descuento 20% limitado
- Cupos limitados
- Early bird pricing
- Ofertas por tiempo limitado
- Promociones especiales
- Lanzamiento con descuento
