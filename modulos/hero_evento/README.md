# 🎉 Hero Evento

Banner principal para eventos, charlas, seminarios y reuniones especiales.

## 📋 Descripción

Diseño elegante de hero banner con gradiente azul corporativo, información de evento (fecha, hora, lugar) y llamada a acción destacada.

## 📐 Especificaciones

- **Ancho**: 600px (email safe)
- **Altura**: ~300px (ajustable)
- **Colores**: Gradiente azul #00b0db
- **Compatibilidad**: Todos los clientes de email

## 🎨 Elementos

- Badge "Evento Académico"
- Título principal (48px, bold)
- Subtítulo (16px)
- 3 información boxes (Fecha, Hora, Lugar)
- Botón CTA principal

## 🔧 Variables Personalizables

```
- Titulo principal
- Subtítulo/descripción  
- Fecha
- Hora
- Lugar/modalidad
- Texto botón CTA
- URL destino botón
```
