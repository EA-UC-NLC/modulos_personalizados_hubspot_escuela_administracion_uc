# 👥 Grid 2x2 - Personas/Speakers

Grid de 4 elementos (2x2) con foto, nombre, cargo y descripción. Ideal para mostrar speakers, facilitadores, testimonios o equipo.

## 📋 Descripción

Layout 2x2 con cards más grandes que permiten mostrar imagen o avatar, junto con información de la persona.

## 📐 Especificaciones

- **Ancho**: 600px total
- **Layout**: 2 columnas x 2 filas
- **Altura card**: 280-300px
- **Imagen**: 100% ancho x 180px alto
- **Sombra**: `0 4px 12px rgba(0,60,90,0.1)`
- **Border radius**: 10px

## 🎨 Estructura de Card

```html
Imagen/Avatar (180px)
↓
Nombre (14px, bold)
↓
Cargo (12px, azul, bold)
↓
Bio/Descripción (11px, gris)
```

## 🔧 Variables Personalizables

```
- Número de cards (agregar/quitar)
- Nombre persona
- Cargo/especialidad
- Descripción bio (2-3 líneas)
- Color fondo (emoji o gradiente)
- Avatar/foto (emoji placeholder)
```
