# 🔀 Divisores y Headers de Sección

Colección de elementos divisores y headers para separar secciones y crear énfasis visual.

## 📋 Descripción

7 variantes de divisores y headers para organizar y estructurar el contenido de emails:
1. Línea simple
2. Línea con icono central
3. Header azul
4. Header gradiente dorado
5. Header azul oscuro
6. Línea gradiente
7. Doble línea

## 📐 Especificaciones

- **Ancho**: 600px
- **Altura**: 1-20px (según tipo)
- **Margin**: 30-40px entre secciones

## 🎨 Variantes

### 1. Línea Simple
```
Altura: 1px
Color: #e0e0e0
```

### 2. Línea con Icono
```
Línea gris + Icono/emoji central
Posición: Z-index con fondo blanco
```

### 3. Header Azul
```
Fondo: #00b0db
Texto: Blanco (22px, bold)
Radius: 8px 8px 0 0
```

### 4. Header Gradiente
```
Fondo: linear-gradient(90deg, #ffd700, #ffed4e)
Texto: #03122E (20px, bold)
Radius: 8px
```

### 5. Header Oscuro
```
Fondo: #03122E
Texto: Blanco (20px, bold)
Radius: 8px
```

### 6. Gradiente
```
Altura: 3px
Gradiente: Azul → Dorado → Azul
```

### 7. Doble Línea
```
2 líneas de 1px con 20px de espacio
```

## 🔧 Variables Personalizables

```
- Texto del header
- Color fondo
- Color texto
- Icono/emoji
- Margin arriba/abajo
```

## 💡 Casos de Uso

**Separadores:**
- Entre secciones del email
- Antes de nuevas temática
- Después de hero banner

**Headers de Sección:**

- ¿POR QUÉ ASISTIR?
