# 🎓 Hero Diplomado

Banner especializado para promoción de diplomados, programas educativos y certificaciones académicas.

## 📋 Descripción

Layout 2 columnas con contenido a la izquierda e icono visual a la derecha. Ideal para destacar programas educativos con datos clave.

## 📐 Especificaciones

- **Ancho**: 600px
- **Layout**: 50% / 50% (2 columnas)
- **Colores**: Azul oscuro corporativo (#4a5f9d) + Dorado (#ffd700)
- **Compatibilidad**: Email clients

## 🎨 Elementos

- Badge tipo "Escuela de Administración"
- Nombre del diplomado (36px)
- Palabra clave destacada en dorado
- Descripción corta
- 3 datos claves (Inicio, Modalidad, Duración)
- Botón "Ver más detalles" dorado
- Icono/decorativo en columna derecha

## 🔧 Variables Personalizables

```
- Nombre diplomado
- Palabra clave (color dorado)
- Descripción
- Fecha inicio
- Modalidad (Presencial/Online/Híbrida)
- Duración
- URL botón
```
