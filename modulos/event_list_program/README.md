# 📋 Listado de Eventos/Programas

Listado vertical con formato fila de eventos, diplomaticos o programas. Compacto, escaneable y fácil de actualizar.

## 📋 Descripción

Cada item es una fila con icono, información (título, fecha, modalidad) y link "Ver más". Ideal para calendarios y catálogos de programas.

## 📐 Especificaciones

- **Ancho**: 600px
- **Altura por item**: ~60-80px
- **Icono**: 32x32px
- **Separadores**: Líneas grises divisoras
- **Tipografía**: Arial 13-15px

## 🎨 Estructura de Item

```html
Icono (32x32) | Título (15px, bold)
              | Fecha + Modalidad (13px)
              | Ver más → (link)
```

## 🔧 Variables Personalizables

```
- Número de items (agregar/quitar filas)
- Icono URL
- Nombre evento/programa
- Fecha inicio
- Modalidad (Presencial/Online/Híbrida)
- Breve descripción
- URL "Ver más"
```
