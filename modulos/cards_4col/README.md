# 📇 Cards 4 Columnas

Grid de 4 tarjetas informativas con iconos en formato horizontal. Perfecto para mostrar características, beneficios o datos clave.

## 📋 Descripción

4 cards idénticas distribuidas en una fila, cada una con icono, título y descripción. Excelente para desglosar información de forma visual.

## 📐 Especificaciones

- **Ancho**: 600px total
- **Cards por fila**: 4
- **Altura card**: 160-180px
- **Icono**: 40x40px (Flaticon CDN)
- **Sombra**: `0 4px 12px rgba(0,60,90,0.12)`
- **Color fondo**: Blanco
- **Color texto**: #03122E (títulos), #666 (desc)

## 🎨 Estructura de Card

```html
Icono
↓
Título (13px, bold)
↓
Descripción (12px, 2 líneas)
```

## 🔧 Variables Personalizables

```
- Número de cards (agregar/quitar)
- Icono URL (Flaticon CDN)
- Título card
- Descripción (texto libre)
- Color de fondo
- Border radius
```
